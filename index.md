<section class="hpd-feature hpd-feature--alt hpd-harness">
  <div class="hpd-wrap hpd-feature__grid">
    <div class="hpd-feature__copy">
      <p class="hpd-eyebrow">Tool harnesses</p>
      <h2>Package what your agent can do. <span class="hpd-quiet">Activate it only when it's needed.</span></h2>
      <p>
        A tool harness is one C# class that holds tools, skills, subagents, and the middleware that guards
        them. Every harness starts collapsed to a single line. Your agent activates the one a request
        needs, picks the right tool inside it, and collapses it again, so even large agents stay fast and focused.
      </p>
      <a class="hpd-text-link" href="/guides/tools/author-a-tool-harness">Build a tool harness <span aria-hidden="true">→</span></a>
    </div>
